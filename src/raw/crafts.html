Every field — the hub

Photography is this library's native language, but not its only one. Eleven more fields now have wings of their own — each a full open studio with the crafts inside it, technique groups, vocabulary, masters, a short history, a first-year curriculum, professional paths, and an honest starter kit. Same building, same rules, different materials.

  • Why this wing exists
  • The seven fields
  • Build your own

Why a photography library grew other wings

Because the shape of learning is the same across crafts, and cross-training is real: musicians practice scales like photographers drill exposure, potters learn centering the way shooters learn histogram reading, and the "steal this" habit works identically in every masters table in this building.

The pattern

Name the vocabulary, group the techniques, meet the masters, trace the history, lay out a syllabus, keep a glossary — in that order, in any field. That is exactly the shape of this library, and it transfers: swap "aperture" for "sauce" or "saddle stitch" and the structure still stands.

The sibling project

This site is modeled on The Open Dojo, a free martial-arts reference library built the same way — styles, kata, techniques, terminology, syllabi, all pure static pages, open whenever you train. Photography and the fighting arts make unlikely-looking twins until you notice both are crafts learned by repetition with attention.

Build your own open studio

This hub is a map of maps. If one of these crafts is yours, the most useful thing you can do is what this library did — write the reference you wish existed.

The pattern, again

  1. Vocabulary — the words beginners pretend to know; define them kindly.
  2. Techniques — grouped, explained, each with a practice line.
  3. Masters — who changed the craft, with dates and works.
  4. History — a timeline; how the craft got to today.
  5. Syllabus — what to learn in what order, honestly paced.
  6. Glossary & search — so the whole thing is findable.

The house rules

Static pages beat frameworks for a reference meant to outlive trends; no tracking beats analytics for readers who trusted you; original prose on factual ground beats scraped aggregation; and corrections from readers aren't insults — they're the second draft arriving for free. Send fields, crafts, and corrections to the editors. The shelf grows the way skills do: repetition with attention.
